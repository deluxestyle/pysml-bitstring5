# pysml

[![PyPI - Version](https://img.shields.io/pypi/v/pysml)](https://pypi.org/project/pysml/)
[![PyPI - Python Version](https://img.shields.io/pypi/pyversions/pysml)](https://pypi.org/project/pysml/)

Python library for EDL21 smart meters using Smart Message Language (SML)

Fork from https://codeberg.org/obi/pysml with bitstring5 update

Can read SML data from physical serial ports, serial-over-tcp or HTTP.

Used by Home Assistant's EDL21 integration.
